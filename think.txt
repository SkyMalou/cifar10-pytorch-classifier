CIFAR-10 图像分类项目规划

一、项目目标

使用 PyTorch 完成一个 CIFAR-10 图像分类项目，训练卷积神经网络识别 10 类图片，并建立完整的训练、验证、测试和结果分析流程。

CIFAR-10 包含 10 个类别：飞机、汽车、鸟、猫、鹿、狗、青蛙、马、船和卡车。图片尺寸为 32×32，训练集有 50000 张图片，测试集有 10000 张图片。

项目最终应做到：
1. 自动下载并加载 CIFAR-10 数据集。
2. 完成数据预处理和数据增强。
3. 搭建并训练一个 CNN 分类模型。
4. 保存最佳模型和训练日志。
5. 在测试集上计算准确率等指标。
6. 绘制损失曲线、准确率曲线和混淆矩阵。
7. 支持使用单张图片进行预测。


二、整体思路

项目采用“先建立可运行基线，再逐步优化”的方式进行。

第一阶段先使用结构简单的 CNN 跑通数据加载、训练、验证和测试流程，确认代码与指标都正确。第二阶段加入数据增强、学习率调度、正则化和更好的网络结构，提高模型的泛化能力。最后对错误分类样本进行分析，判断模型主要在哪些类别上容易混淆。

整体流程：

数据准备
→ 数据预处理与增强
→ 划分训练集和验证集
→ 建立 CNN 模型
→ 设置损失函数与优化器
→ 训练并记录指标
→ 保存验证集表现最好的模型
→ 在测试集上评估
→ 可视化结果并分析错误样本
→ 编写单张图片预测程序


三、技术方案

1. 开发语言：Python
2. 深度学习框架：PyTorch
3. 数据处理：torchvision
4. 指标计算：scikit-learn
5. 图表绘制：Matplotlib、Seaborn
6. 日志工具：TensorBoard，可选
7. 运行设备：优先使用 CUDA GPU，没有 GPU 时自动使用 CPU

五、具体实施步骤

第 1 步：搭建环境

安装 PyTorch、torchvision、Matplotlib、scikit-learn、Seaborn 和 TensorBoard。确认 PyTorch 能正确识别 GPU，并固定随机种子，使实验结果尽量可复现。

第 2 步：准备数据

使用 torchvision.datasets.CIFAR10 自动下载数据。训练集进一步划分为训练子集和验证集，例如 45000 张用于训练、5000 张用于验证，官方测试集只用于最终评估。

训练集建议使用以下处理：
- RandomCrop：随机裁剪并添加 padding。
- RandomHorizontalFlip：随机水平翻转。
- ToTensor：转换为张量。
- Normalize：按照 CIFAR-10 的均值和标准差归一化。

验证集和测试集只进行 ToTensor 与 Normalize，不使用随机数据增强。

第 3 步：建立基线模型

先实现一个简单 CNN，建议包含 3 个卷积模块。每个模块由卷积层、BatchNorm、ReLU 和池化层组成，最后使用全连接层输出 10 个类别的 logits。

基线模型的意义是确认完整流程正确，不要求一开始就达到最高准确率。

第 4 步：配置训练过程

建议初始配置：
- batch_size：128
- epoch：30～50
- 损失函数：CrossEntropyLoss
- 优化器：AdamW 或 SGD + momentum
- 初始学习率：AdamW 可用 0.001，SGD 可用 0.1
- 权重衰减：5e-4
- 学习率调度器：CosineAnnealingLR 或 ReduceLROnPlateau

每个 epoch 记录训练损失、训练准确率、验证损失和验证准确率。以验证准确率为依据保存最佳模型，避免只保存最后一轮模型。

第 5 步：测试与评估

加载验证集表现最好的模型，在测试集上计算：
- 总体准确率。
- 每个类别的准确率。
- Precision、Recall 和 F1-score。
- 10×10 混淆矩阵。

测试阶段必须关闭梯度计算，并将模型切换到 eval 模式。

第 6 步：结果可视化

至少输出以下图表：
- 训练损失与验证损失曲线。
- 训练准确率与验证准确率曲线。
- 混淆矩阵。
- 若干正确预测样本。
- 若干错误预测样本，并标出真实类别和预测类别。

第 7 步：实现单图预测

predict.py 接收图片路径，执行与测试集一致的预处理，加载最佳模型，输出预测类别和每个类别的概率。由于 CIFAR-10 图片尺寸较小，外部图片需要缩放到 32×32。


六、优化方向

完成基线后，可以逐项实验，不要同时修改太多设置，否则难以判断提升来自哪里。

1. 增加 BatchNorm 和 Dropout。
2. 比较 AdamW 与 SGD 优化器。
3. 调整学习率、batch_size 和训练轮数。
4. 使用更强的数据增强，如 RandomErasing、Cutout、Mixup 或 CutMix。
5. 将普通 CNN 替换为 ResNet18，并针对 32×32 图片调整第一层卷积和池化层。
6. 使用标签平滑减少过拟合。
7. 使用早停策略避免无效训练。
8. 使用混合精度训练提高 GPU 训练速度。


七、实验记录方式

每次实验建议记录：
- 实验名称和日期。
- 模型结构。
- 数据增强方案。
- 优化器与学习率。
- batch_size 和 epoch 数量。
- 最佳验证准确率。
- 最终测试准确率。
- 训练耗时。
- 本次实验的结论。

一次只改变一个主要变量，方便进行公平对比。


八、验收标准

基础完成标准：
1. 所有脚本可以正常运行。
2. 能自动下载并读取 CIFAR-10。
3. 训练过程中损失总体下降。
4. 能保存和重新加载模型。
5. 能输出测试准确率和混淆矩阵。
6. 能对单张图片进行预测。

效果目标：
- 简单 CNN 测试准确率争取达到 75%～82%。
- 经过合理优化的 ResNet18 测试准确率争取达到 90% 左右或更高。


九、建议开发顺序

1. 编写 dataset.py，检查图片和标签是否正确。
2. 编写 model.py，用随机张量检查输出形状是否为 [batch_size, 10]。
3. 编写 train.py，先用少量数据训练 1～2 个 epoch，验证流程。
4. 加入验证集、最佳模型保存和日志记录。
5. 编写 test.py，输出完整评估指标。
6. 增加训练曲线和混淆矩阵。
7. 编写 predict.py。
8. 在基线稳定后尝试 ResNet18 和其他优化方案。


十、最终交付成果

1. 一套结构清晰、可直接运行的 Python 源代码。
2. requirements.txt 依赖文件。
3. 训练完成的最佳模型权重。
4. 训练与验证曲线。
5. 测试集指标和混淆矩阵。
6. 错误样本分析结果。
7. 项目说明文档，包括环境安装、训练、测试和预测命令。


十一、第一版实施建议

第一版先完成“简单 CNN + 基础数据增强 + AdamW + 最佳模型保存 + 测试评估”。确认整个项目稳定运行后，再增加 ResNet18、Mixup、CutMix 和混合精度训练。这样每一步都有明确结果，也更容易定位问题。
